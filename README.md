# uTools Lite

一个轻量、离线优先的 Windows 快捷启动器。通过全局快捷键快速搜索应用和文件，也可以直接使用计算器、笔记、稿纸、金额转换、OCR 文字识别和加密凭据管理等内置工具。

![uTools Lite 图标](build/icon.png)

## 功能特点

- **快速唤起**：默认使用 `Alt + Space`，可在系统设置中修改。
- **应用搜索**：搜索传统桌面程序、快捷方式和 Windows 商店应用。
- **文件搜索**：优先联动本机 Everything；未安装 Everything 时使用内置本地索引。
- **即时计算**：在搜索框直接输入算式，回车复制结果。
- **插件工具**：内置笔记、计算稿纸、金额转换、时间戳转换、OCR 文字识别和密码本，也支持从文件夹或 ZIP 安装插件。
- **服务器凭据**：密码本支持主机、端口、协议、环境、认证方式、SSH 密钥路径和普通网站账号。
- **本机加密**：密码库使用 AES-256-GCM 加密，主密码不写入磁盘。
- **系统外观**：支持跟随系统、浅色和深色模式。
- **本地数据管理**：可以从设置页打开应用数据与诊断日志目录。

## 安装

本项目目前支持 Windows x64。

1. 下载仓库内的 [uTools Lite 0.1.3 安装包](release/uTools%20Lite%20Setup%200.1.3.exe)。
2. 退出正在运行的旧版本，包括系统托盘中的 uTools Lite。
3. 运行安装程序完成安装。
4. 首次启动会显示主窗口，之后可用 `Alt + Space` 随时唤起。

如果更新后桌面快捷方式仍显示旧图标，请删除旧快捷方式，然后从开始菜单重新创建。

## 使用方法

打开主窗口后直接输入内容：

| 输入内容 | 功能 |
| --- | --- |
| 应用名称 | 查找并启动应用 |
| 文件名 | 查找并打开文件 |
| `2+2*2` | 计算并复制结果 |
| `笔记` | 打开本地笔记 |
| `稿纸` | 打开计算稿纸 |
| `金额` | 打开金额转换工具 |
| `OCR` / `文字识别` | 打开离线 OCR，识别剪贴板截图或本地图片 |
| `密码` 或 `服务器` | 打开加密凭据空间 |

使用方向键切换结果，按回车打开，按 `Esc` 隐藏窗口。

## 系统设置

点击搜索框右侧的设置按钮，可以管理：

- 全局唤起快捷键；
- 开机自动启动；
- 跟随系统、浅色或深色外观；
- 本地数据目录和诊断日志目录；
- 当前文件索引来源、数量和状态。

设置保存在应用的数据目录中。重要设置采用临时文件写入和原子替换，并保留上一版设置用于异常恢复。

## 文件搜索与索引

应用有两种文件搜索方式：

1. **Everything**：检测到本机 Everything 时优先使用，适合全盘快速搜索。
2. **内置索引**：没有 Everything 时在后台建立内存索引，当前上限为 600,000 条。

600,000 条是应用的内存保护上限，不是 Windows 的文件数量限制。达到上限后，较晚扫描的目录可能无法进入索引。文件数量较多时建议安装 [Everything](https://www.voidtools.com/zh-cn/)。

## 密码库与数据安全

- 密码库的加密密文存放在统一 SQLite 数据库中，内容使用 AES-256-GCM 加密。
- 主密码只保留在当前运行进程的内存中，不会直接保存到磁盘。
- 密码库闲置后自动锁定，复制密码后会尝试定时清理剪贴板。
- 保存前保留上一版加密文件。
- 可以导出独立的加密备份；恢复备份需要对应的主密码。
- 忘记主密码后无法恢复密码库内容，请妥善保存主密码和加密备份。

更详细的密码库说明见 [plugins/password/README.md](plugins/password/README.md)。

## 本地数据目录

数据默认保存在 Electron 的用户数据目录，Windows 下通常位于：

```text
%APPDATA%/utools-lite/
├── data/
│   ├── utools-lite.db            # 设置、授权和全部插件业务数据
│   └── utools-lite.db.previous   # 数据库上一版备份
├── settings.json                 # 迁移前设置，只读保留用于回滚
├── plugin-permissions.json       # 迁移前授权记录，只读保留用于回滚
├── plugins/                      # 用户安装的插件
├── plugin-data/                  # 迁移前插件数据，只读保留用于回滚
└── logs/                         # 自动轮转的诊断日志
```

首次启动新版时，程序会将现有密码本、笔记、计算稿纸、设置和插件授权完整导入 SQLite。旧文件不会自动删除；数据库完成迁移后，新的业务数据只写入 `utools-lite.db`。

密码、剪贴板正文等敏感内容不会写入诊断日志。向他人提供日志前，仍建议检查其中是否含有本机文件名或环境信息。

## 本地开发

### 环境要求

- Windows 10 或 Windows 11
- Node.js 20 或更高版本
- npm

### 安装依赖

```bash
npm install
```

### 启动开发版本

```bash
npm run dev
```

### 检查与构建

```bash
# TypeScript 类型检查
npm run typecheck

# 构建主进程和界面
npm run build

# 插件集成检查
npm run smoke

# 生成 Windows 安装包
npm run dist
```

安装包输出到 `release/` 目录。

## 项目结构

```text
src/
├── main/          # Electron 主进程、搜索、索引、插件宿主和数据保存
├── preload/       # 主界面与插件详情页的安全桥接
├── renderer/      # React 搜索界面和系统设置
└── shared/        # IPC 类型和共享数据结构
plugins/           # 内置插件
plugin-host/       # 插件独立进程运行环境
build/             # 应用图标和打包资源
scripts/           # 检查与打包脚本
```

## 插件安全模型

插件逻辑运行在独立进程中，不能直接访问主界面。文件、剪贴板和网络能力由宿主统一代理，并根据插件清单中的权限声明进行检查。

插件相对路径默认写入自己的私有数据目录。访问其他目录时，应用会在主界面显示授权请求。

## 当前限制

- 当前主要面向 Windows x64。
- 内置文件索引不持久化，重启应用后会重新建立。
- 内置索引达到 600,000 条后会停止继续收录。
- 安装包暂未进行商业代码签名，Windows 可能显示来源提示。
